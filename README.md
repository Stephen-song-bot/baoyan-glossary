# 保研政策名词全解

一份给本科生的推免（保研）政策术语参考手册，按"资格 → 接收 → 系统 → 加分 → 博弈 → 学科"六个环节分类，并附易混淆辨析与完整时间线。

在线阅读：本仓库已开启 GitHub Pages，直接访问 `index.html` 对应地址即可。

## 内容结构

| 章节 | 内容 |
|---|---|
| 一、资格类 | 推免资格、名额、保研率、加权平均分、GPA、挂科一票否决、重修与刷分、递补、破格、专项计划 |
| 二、接收类 | 夏令营（含 2025 年取消潮）、交流营 / 开放日、预推免、九推、十推、优营、铁 offer、候补 |
| 三、系统操作类 | 推免服务系统、平行志愿、48 小时锁定期、复试通知、待录取、服从调剂、拟录取 |
| 四、评价加分类 | 综测、加分细则、白名单竞赛、大创、论文署名、期刊分级、学硕专硕直博、四六级 |
| 五、出身与博弈类 | 985/211/双非、本科出身、报录比、保底校与冲刺校、联系导师 |
| 六、专业与学科类 | 跨保、一级/二级学科、专业代码、学科评估、导师与课题组 |
| 七、易混淆辨析 | 8 个最容易踩的坑 |
| 八、时间线 | 从大三下到 10 月补录的完整节点表 |

## 特性

- 单文件 HTML，无任何外部依赖（CSS、JS 全部内联），国内可直接打开
- 顶部搜索框可按关键词实时过滤词条
- 自动适配系统浅色 / 深色模式
- 内置打印样式，可直接打印或另存为 PDF

## 免责说明

整理自教育部《全国硕士研究生招生工作管理规定》及各高校公开推免信息。
具体数字、日期、加分细则**一律以本校教务处当年发布的推免文件为准**。
